# 🎮 길드정산 — 스마트폰 앱

길드 다이아 분배·정산을 폰에서 전부 처리하는 PWA입니다.
데이터는 기존 구글시트 그대로 두고, 화면만 Vercel로 분리했습니다.

```
[폰 홈화면 앱]  →  [Vercel 서버]  →  [Apps Script]  →  [구글시트]
   화면              토큰 보관·인증        기존 정산 로직        진짜 데이터
```

**처음 설치한다면 → [`docs/SETUP.md`](docs/SETUP.md).**
쓰던 스프레드시트는 건드리지 않고, 새 파일에서 전부 준비한 뒤 마지막에 데이터만 옮깁니다.

## 무엇이 달라졌나

| | 기존 (v7.4) | 지금 (v10.0) |
|---|---|---|
| 접속 | 구글 로그인 필요 | 링크만 있으면 바로 열림 |
| 화면 수정 | `.gs` 안의 HTML 문자열을 고침 | 저장소 파일 수정 → push → 자동 배포 |
| 길드원 | 별도 `?view=lookup` 링크 | 같은 앱에서 자유롭게 조회 |
| 관리 기능 | 링크를 아는 사람 누구나 | **PIN을 아는 사람만** |
| 홈 화면 | 웹 바로가기 | 아이콘·전체화면 앱 (PWA) |
| 혈맹원 관리 | PC 시트 메뉴 | 앱에서 추가·아이디 변경·탈퇴 |
| 정정·삭제·시즌종료 | PC 시트 메뉴 전용 | **앱에서 전부** (확인 문구로 보호) |
| 버전 이전 | 쓰던 파일에 덮어쓰기 | **새 파일에서 준비 → 데이터만 이관** (무중단) |
| 분배 비중 | 전원 똑같이 1/N | **멤버별 1~100%** · 남는 몫은 혈맹운영비로 |
| 소통 | 없음 | **게시판 + 공지** (공지는 항상 화면 맨 위) |
| 연합 | 없음 | **연합 탭** — 서버별 누적, 인증샷은 인원수만 |
| 권한 | 관리자 하나 | 관리자 + **마스터관리자**(앱 이름·PIN 교체) |
| 언어 | 한국어 | 한국어 / 中文 (화면 문구 · 이름은 번역 안 함) |

> 🚨 **v10.0 을 붙여넣은 뒤 반드시 한 번** — 앱 `[⚙️ 관리] → 관리 도구 →`
> `[🏦 혈비 계정을 혈맹운영비로 통일]`. 계정명이 코드 상수와 어긋나면 다음 분배 때
> 운영비 계정이 하나 더 생깁니다. 잔액·참여횟수는 그대로 따라갑니다.
>
> 🚨 **v9.1 이상 필수** — v9.0 이하에서는 웹앱 액세스를 "모든 사용자"로 열면
> `/exec` 주소를 아는 사람이 브라우저로 구버전 화면을 열어 **PIN 없이 등록·분배·지급**을
> 할 수 있었습니다. 토큰 검사가 `doPost` 에만 있었기 때문입니다.
> v9.1 에서 해당 화면을 삭제해 막았습니다.
> 본인 잔액 조회(`?view=lookup`)는 읽기 전용이라 그대로 남아 있습니다.

## 권한 구분

| | 조회 | 게시판 글쓰기 | 등록·분배·지급 | 앱 이름·관리자 PIN 변경 |
|---|---|---|---|---|
| 길드원 (링크만) | ✅ | ✅ | ❌ | ❌ |
| 관리자 (`ADMIN_PIN`) | ✅ | ✅ + 공지 | ✅ | ❌ |
| 마스터관리자 (`MASTER_PIN`) | ✅ | ✅ + 공지 | ✅ | ✅ |

PIN은 앱 하단 **[⚙️ 관리]** 탭에서 입력합니다. 한 번 넣으면 그 기기에서 30일 유지되고, 같은 탭에서 잠글 수 있습니다.

**마스터관리자(개발자)** 는 관리자가 하는 일 전부에 더해 앱 이름과 **관리자 PIN을 앱에서 바로 바꿀 수 있습니다.**
관리자가 교체돼도 Vercel 재배포 없이 PIN만 갈면 됩니다. `MASTER_PIN` 을 넣지 않으면 이 기능만 잠기고 나머지는 그대로 동작합니다.

## 화면 구성

- **💰 잔액** — 멤버별 분배전/분배완료/참여횟수, 이름 검색, "받을 잔액 남은 사람만 보기". 관리자에게는 `[지급]` 버튼이 보입니다.
- **📦 아이템** — 미분배 아이템 목록. 관리자에게는 `[분배]` 버튼과 등록 폼(사진 OCR 자동 참여자 감지 포함)이 보입니다.
  분배 미리보기는 **비중이 다른 사람의 금액까지 따로** 보여줍니다.
- **📋 게시판** — 혈맹원 누구나 글을 씁니다(PIN 불필요). 공지는 관리자만 올릴 수 있고 **항상 화면 맨 위**에 뜹니다.
- **🤝 연합** — 서버(01~12)·금액·아이템명·비중(%)을 넣으면 그 서버에 누적됩니다.
  인증샷은 **인원수만** 세고 아이디는 판별하지 않습니다. 혈맹 내부 잔액과 완전히 분리된 장부입니다.
- **🙋 내 정보** — 이름을 고르면 본인 숫자만. 한 번 고르면 다음부터 자동으로 불러옵니다.
- **⚙️ 관리** — **한국어/中文 전환**, PIN 잠금 해제/잠그기, **길드원에게 공유하기(QR·링크 복사·공유 시트)**, 앱 설치 방법, 설정 점검.
  관리자에게만: **혈맹원 관리**(추가·아이디 변경·탈퇴·**분배비중·서버·한자표기**), **아이디 변경 이력**, 관리 도구, 기록용 이메일.
  마스터관리자에게만: **앱 이름 변경 · 관리자 PIN 교체**.

## 환경변수 (Vercel → Settings → Environment Variables)

| 이름 | 값 | 어디서 |
|---|---|---|
| `GAS_URL` | `https://script.google.com/macros/s/.../exec` | Apps Script [배포] 후 나오는 주소 |
| `GAS_TOKEN` | 48자 임의 문자열 | 시트 메뉴 → `[🔑 웹 API 토큰]` |
| `ADMIN_PIN` | 관리자 비밀번호 | 직접 정함 (6자리 이상 권장) |
| `SESSION_SECRET` | 긴 임의 문자열 | `openssl rand -base64 32` |
| `MASTER_PIN` | (선택) 마스터관리자 PIN | 직접 정함 · `ADMIN_PIN` 과 **달라야** 함 |

전부 **서버에만** 저장되고 브라우저로 내려가지 않습니다.
`MASTER_PIN` 은 비워둬도 됩니다 — 마스터 기능만 잠기고 나머지는 그대로 동작합니다.

## 로컬에서 돌려보기

**진짜 스프레드시트도, Apps Script 배포도, 환경변수도 필요 없습니다.**

```bash
npm install
npm run dev:mock     # http://localhost:3000 · 관리자 PIN 1234
```

가짜 시트가 함께 뜨고, 등록·분배·지급이 실제로 숫자를 움직입니다. 화면만 고칠 땐 이것만 쓰면 됩니다.
진짜 시트에 붙이고 싶으면 `.env.example` 을 `.env.local` 로 복사해 값을 채우고 `npm run dev`.

| 명령 | 설명 |
|---|---|
| `npm run verify` | **커밋 전 이거 하나** — 타입·린트·`.gs` 검사·빌드·E2E 전부 |
| `npm run verify:gs` | 26개 항목 — `.gs`(구문·**doGet 화면의 쓰기 차단**·라우터 노출면·락·분배 산식 5,069건 대조·확인 게이트·보호훅) + `app/api` 권한 경계(관리자 인증·마스터 게이트·공지 권한·확인값 전달) |
| `npm run e2e` | 권한 경계 + 화면 흐름 60건 (`npm run build` 먼저) |
| `npm run shots` | 주요 화면 촬영 + 합본 3장 → `shots/` |
| `npm run build` | 배포와 동일한 빌드 |
| `npm run icons` | 아이콘 PNG 다시 생성 |

push하면 GitHub Actions가 같은 검사를 자동으로 돌립니다.

> 코드를 고치기 전에 [`CLAUDE.md`](CLAUDE.md) 를 읽으세요 — 어디를 고쳐야 하는지,
> 절대 건드리면 안 되는 불변식이 무엇인지 정리돼 있습니다.

## 안전장치

- **토큰 인증** — Apps Script는 `API_TOKEN`이 일치하는 요청만 처리합니다. 웹앱 주소를 알아도 토큰 없이는 아무것도 못 합니다.
- **PIN + 서명 쿠키** — 관리자 세션은 `SESSION_SECRET`으로 서명돼 위조할 수 없습니다. PIN 시도는 10분에 10회로 제한됩니다.
- **동시 실행 직렬화** — 등록·분배·지급은 Apps Script `LockService`로 한 번에 하나씩 처리되어, 여러 명이 동시에 눌러도 잔액이 꼬이지 않습니다.
- **위험도에 비례하는 확인** — 모든 기능이 앱에 있지만, 되돌릴 수 없는 작업(시즌 종료·데이터 이관·최초 설치·공장 초기화)은 정해진 문구를 정확히 입력해야만 실행됩니다. 이 검사는 서버에서 합니다.
- **되돌릴 수 없으면 먼저 막는다** — 이미 지급된 사람이 포함된 아이템은 정정·삭제가 아예 시작되지 않습니다. 부분 반영은 절대 허용하지 않습니다.
- **되돌릴 수 없는 작업은 2단계** — ① 이미 있는 이름으로 아이디를 바꾸면 두 계정이 합쳐집니다. ② 잔액이 남은 사람을 탈퇴시키면 받지 못한 다이아가 남습니다. 둘 다 앱이 상황을 보여주고 한 번 더 확인받기 전까지 서버가 거부합니다.
- **탈퇴는 기록을 지우지 않음** — 명단에서만 빼고, 잔액·참여 이력이 있으면 `(미등록)`으로 보존합니다.
- **금액은 캐시하지 않음** — 서비스워커는 화면 껍데기만 캐시하고 `/api` 응답은 절대 저장하지 않습니다.
- **되돌리기는 그때 준 금액 그대로** — 분배 시점의 개인별 금액을 `[분배대기중]` "분배내역" 열에 남깁니다. 나중에 비중을 바꿔도 정정·삭제가 정확히 되돌아갑니다.
- **공개 쓰기는 게시판 하나뿐** — 정산 데이터에 접근하지 않고, 한 기기당 10분 5건으로 제한되며, 공지 권한은 요청 본문이 아니라 **쿠키로만** 정해집니다.
- **이름은 기계가 짓지 않는다** — 한/중 전환은 화면에 고정된 문구만 바꿉니다. 혈맹원 한자 표기는 관리자가 직접 확인해 넣은 값만 씁니다.

토큰이 새어나갔다고 판단되면 시트 메뉴에서 재발급 → Vercel `GAS_TOKEN` 교체 → Redeploy 하면 즉시 무효화됩니다.
