# 설치 가이드 — 쓰던 시트를 건드리지 않고 옮기기

**지금 운영 중인 스프레드시트는 끝까지 그대로 둡니다.**
새 파일에서 전부 준비하고, 마지막에 데이터만 한 번에 옮깁니다.
옮기기 전까지는 기존 방식으로 계속 정산하시면 됩니다.

```
 [기존 시트]  ← 계속 정산 (그대로)
      │
      │  ⑤ 준비 끝나면 데이터만 복사 (읽기만 함)
      ▼
 [새 시트] + [새 앱]  ← ①~④ 에서 준비
```

| | 무엇 | 어디서 | 기존 시트 영향 |
|---|---|---|---|
| ① | 새 스프레드시트 만들기 | 구글 드라이브 | 없음 |
| ② | v10.0 설치 + 웹앱 배포 | 새 시트의 Apps Script | 없음 |
| ③ | Vercel 배포 | vercel.com | 없음 |
| ④ | 폰에서 확인 | 폰 | 없음 |
| ⑤ | **데이터 이관** | 새 시트 메뉴 | **읽기만** |

---

## ① 새 스프레드시트 만들기

1. [sheets.new](https://sheets.new) 로 빈 스프레드시트 생성
2. 이름을 알아보기 쉽게 (예: `길드정산 v8`)

## ② v10.0 설치 + 웹앱 배포

1. 새 시트에서 **확장 프로그램 → Apps Script**
2. 기본 코드를 지우고, [**GuildManager_v10_1.gs 전체**](https://raw.githubusercontent.com/rhrjsgks-jarvis/guild/main/apps-script/GuildManager_v10_1.gs) 를 복사해 붙여넣기 (Ctrl+A → Ctrl+C → Ctrl+V) → 💾 저장
3. 시트로 돌아와 새로고침 → 메뉴 **[🎮 길드정산] → [🚀 최초 설치]**
   - 빈 시트 구조가 만들어집니다 (데이터는 아직 없음)
4. Apps Script 우측 상단 **[배포] → [새 배포]**

   | 항목 | 설정값 |
   |---|---|
   | 유형 (⚙️) | **웹 앱** |
   | 실행 계정 | **나** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** ← 필수 |

   → 나오는 `.../exec` 주소 복사 = **`GAS_URL`**

5. 시트 메뉴 **[🔑 웹 API 토큰]** → 48자 토큰 복사 = **`GAS_TOKEN`**

> 🚨 **반드시 v9.1 이상을 쓰세요.** v9.0 이하에서는 액세스를 "모든 사용자"로 열면
> 이 주소를 아는 사람이 브라우저로 열어 PIN 없이 등록·분배·지급을 할 수 있었습니다.
>
> **"모든 사용자"로 열어도 되나요?**
> Vercel 서버에는 구글 로그인 세션이 없어서 "나만"으로는 아예 연결되지 않습니다.
> 대신 위 토큰이 없는 요청은 전부 거부됩니다. 토큰은 Vercel 서버에만 저장되고
> 브라우저로 내려가지 않으며, 새어나갔다 싶으면 메뉴에서 재발급하면 즉시 무효가 됩니다.

## ③ Vercel 배포

[**vercel.com/new**](https://vercel.com/new) → `rhrjsgks-jarvis/guild` **Import**

- **Project Name**: `guild-manager` → 주소가 `https://guild-manager.vercel.app` 이 됩니다
- **Environment Variables** — 앞의 4개는 필수, 마지막 하나는 선택:

  | Key | Value |
  |---|---|
  | `GAS_URL` | ②-4 의 `.../exec` |
  | `GAS_TOKEN` | ②-5 의 토큰 |
  | `ADMIN_PIN` | 직접 정하는 관리자 비밀번호 (6자리 이상 권장) |
  | `SESSION_SECRET` | 아무 긴 임의 문자열 |
  | `MASTER_PIN` | (선택) 마스터관리자 PIN — **`ADMIN_PIN` 과 다른 값**이어야 합니다 |

  `MASTER_PIN` 을 넣으면 앱에서 **앱 이름**과 **관리자 PIN**을 직접 바꿀 수 있습니다.
  관리자가 바뀔 때 Vercel을 다시 만지지 않아도 됩니다. 비워두면 그 기능만 잠깁니다.

- **Deploy**

빌드 설정은 손대지 마세요 (Next.js 자동 인식).

## ④ 확인

`https://guild-manager.vercel.app/api/health` → `"ok": true` 면 성공.
아니면 무엇이 잘못됐는지 한국어로 나옵니다. → [자주 막히는 곳](#자주-막히는-곳)

폰에서 앱 주소를 열고:
- **iPhone(사파리)** — 공유 ⬆️ → 홈 화면에 추가
- **Android(크롬)** — ⋮ → 앱 설치

**이 단계에서 충분히 만져보세요.** 아직 데이터가 없으니 뭘 눌러도 안전합니다.

## ⑤ 데이터 이관 (준비가 끝났을 때)

새 시트 메뉴 **[🎮 길드정산] → [📥 기존 길드정산 파일에서 가져오기]**
→ 기존 스프레드시트 URL 붙여넣기 → 확인

가져오는 것: **멤버DB · 잔액현황 · 분배대기중 · 지급기록 · 작업기록**

- **기존 파일은 읽기만 하고 전혀 바꾸지 않습니다.**
- **덮어쓰기 방식**이라 여러 번 실행해도 결과가 같습니다.
  옮긴 뒤 기존 시트에서 며칠 더 쓰다가 다시 실행해도 안전합니다.
- 멤버DB에 없는 옛 이름도 잔액이 남아 있으면 버리지 않고 보존합니다.

이관 후 **[🔁 참여횟수 재계산]** 과 **[🏦 혈비 계정을 혈맹운영비로 통일]** 을 한 번씩 실행하고,
앱에서 잔액이 기존 시트와 같은지 확인하세요.

> ⚠️ **새 시트에서 정산을 시작한 뒤에는 다시 실행하지 마세요.** 그 작업이 사라집니다.
> 이미 한 번 실행했다면 확인 팝업이 날짜와 함께 경고해줍니다.

전환이 끝나면 기존 시트는 읽기 전용으로 남겨두시길 권합니다 (혹시 모를 대조용).

## 앞으로

### 화면을 바꾸고 싶을 때
Claude에게 말하면 → push → Vercel이 1~2분 뒤 자동 반영. **아무것도 안 하셔도 됩니다.**

### 관리 작업은 전부 앱에서
[⚙️ 관리] 탭 아래쪽 **관리 도구** 에 시즌 종료·데이터 이관·초기화가 있고,
[📦 아이템] 탭 아래쪽 **등록된 모든 아이템** 에서 정정·삭제를 합니다.

### 정산 로직(.gs)을 바꿨을 때
1. 새 `.gs` 를 Apps Script에 붙여넣기
2. **[배포] → [배포 관리] → 편집(✏️) → 버전: 새 버전 → [배포]**
   ⚠️ **[새 배포]가 아닙니다.** 그렇게 하면 URL이 바뀌어 `GAS_URL` 도 고쳐야 합니다.

### v9 에서 v10 으로 올릴 때 — 딱 한 가지만 더
위 2단계를 마친 뒤 앱 **[⚙️ 관리] → 관리 도구 → [🏦 혈비 계정을 혈맹운영비로 통일]** 을 한 번 실행하세요.
`유일배분(혈비)` 계정을 새 이름으로 옮깁니다 (잔액·참여횟수 그대로).
**안 하면 다음 분배 때 운영비 계정이 하나 더 생깁니다.**

### 분배비중 (v10.0)
앱 **[⚙️ 관리] → 혈맹원 관리 → [관리]** 에서 사람마다 1~100% 를 정할 수 있습니다. 기본은 100%.

```
1만 다이아를 10명이 나누고, 그중 한 명이 50% 일 때
  혈맹운영비  1,000   (10%)
  기본 1인당    900   (9,000 ÷ 10명)
  50% 대상자    450
  남은 450 도 혈맹운영비로  →  운영비 최종 1,450
```

비중을 바꿔도 **이미 분배된 아이템에는 영향이 없습니다.** 그때 각자에게 실제로 들어간 금액이
`[분배대기중]` 시트 **"분배내역"** 열에 남아 있어서, 나중에 정정·삭제해도 정확히 되돌아갑니다.

### 게시판 · 연합 (v10.0)
- **📋 게시판** — 혈맹원 누구나 글을 씁니다(PIN 불필요). **공지는 관리자만** 올릴 수 있고,
  올리면 어느 탭에 있든 화면 맨 위에 뜹니다.
- **🤝 연합** — 서버(01~12) · 금액 · 아이템명 · 비중(%)을 넣으면 그 서버에 누적됩니다.
  인증샷을 올리면 **인원수만** 자동으로 세고, 누구인지는 판별하지 않습니다.
  혈맹 내부 잔액과는 완전히 분리된 장부입니다.

### 중국어 병기 (v10.0)
- **[⚙️ 관리] → 언어**에서 한국어 / 中文 을 고릅니다. 바뀌는 것은 **화면에 고정된 문구**뿐입니다.
- 혈맹원 이름 옆 한자는 **[혈맹원 관리] → [관리] → 한자표기**에 직접 넣어주세요.
  시스템이 이름을 추측해서 짓지 않습니다 — 잘못 지으면 다른 사람으로 읽혀 다이아가 엉뚱한 곳으로 갑니다.

### 혈맹원 관리 (가입 · 아이디 변경 · 탈퇴)
앱 **[⚙️ 관리] → 혈맹원 관리** (PIN 필요)

| 상황 | 하는 일 |
|---|---|
| 새로 가입 | **[➕ 혈맹원 추가]** → 아이디 입력. 참여자현황·잔액현황 행이 자동 생성 |
| 게임에서 개명 | 해당 인원 **[관리] → 아이디 수정 → [변경하기]** |
| 탈퇴 | 해당 인원 **[관리] → [➖ 탈퇴 처리]** |

- 아이디는 **게임에서 보이는 이름과 정확히 같게** 입력하세요 (띄어쓰기·괄호·한자 포함).
  그래야 인증샷 OCR이 자동으로 찾아냅니다.
- **변경** 시 잔액·참여횟수가 새 이름으로 그대로 따라갑니다.
  이미 있는 이름으로 바꾸면 두 계정이 합쳐지므로, 앱이 양쪽 잔액을 보여주며 한 번 더 확인받습니다.
- **탈퇴**는 명단에서만 빼고 **기록은 남깁니다.** 잔액이나 참여 이력이 있으면 잔액현황에
  `(미등록)` 회색으로 보존되고, 이력이 전혀 없을 때만 목록에서 사라집니다.
  받지 않은 잔액이 남아 있으면 한 번 더 확인을 받습니다 — 먼저 [잔액] 탭에서 지급하는 편이 깔끔합니다.
- 모든 변경은 **[작업기록]** 시트에 영구히 남습니다.

## 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| "구글이 로그인 화면을 돌려줬습니다" | 배포 액세스가 "모든 사용자"가 아님 | [배포 관리] → 편집 → 액세스: **모든 사용자** → 새 버전 |
| "API 토큰이 아직 발급되지 않았습니다" | 토큰 미발급 | 메뉴 **[🔑 웹 API 토큰]** 1회 실행 |
| "인증에 실패했습니다" | `GAS_TOKEN` 이 시트의 토큰과 다름 | 메뉴에서 현재 토큰 확인 → Vercel 값 교체 → **Redeploy** |
| "doPost 함수가 없을 수 있습니다" | 코드 붙여넣고 재배포를 안 함 | [배포 관리] → 새 버전 |
| 환경변수를 고쳤는데 그대로 | Vercel은 재배포해야 반영 | Deployments → ⋯ → **Redeploy** |
| 가져오기에서 "파일을 열 수 없습니다" | URL이 틀렸거나 열람 권한 없음 | 같은 구글 계정으로 열리는 파일인지 확인 |
| 사진 첨부해도 참여자 자동 체크 안 됨 | Advanced Drive Service 미활성 | Apps Script **[서비스] → [+] → "Drive API"** (사진 저장·링크는 없어도 됨) |
| 특정 멤버만 OCR로 안 잡힘 | 시트 이름 ≠ 게임 표시 이름 | 앱에서 아이디를 게임과 똑같이 변경, 또는 멤버DB **D열 게임표시명** 입력 |
| PIN을 잊음 | — | 마스터관리자면 앱에서 바로 변경 · 아니면 Vercel `ADMIN_PIN` 변경 → Redeploy |
| 잔액현황에 운영비 계정이 두 개 | v10 붙여넣고 계정명 통일 도구를 안 돌림 | **[🏦 혈비 계정을 혈맹운영비로 통일]** 실행 |
| 마스터 PIN 을 넣었는데 관리자로만 로그인됨 | `MASTER_PIN` 이 `ADMIN_PIN` 과 같은 값 | 서로 다른 값으로 바꾸고 Redeploy |
| PIN 을 바꿨는데 옛 PIN 도 통함 | 이미 잠금 해제된 기기는 30일 세션이 남아 있음 | 그 기기에서 [관리] → 잠그기 |

## 앱에서 할 수 있는 것 — 전부입니다 (v10.0)

PC 시트를 열 일이 없습니다. 위험한 기능일수록 확인 절차가 강해질 뿐입니다.

| 어디서 | 무엇 | 확인 절차 |
|---|---|---|
| 📦 아이템 | 등록 · 분배 | 참여자 명단 재확인 |
| 📦 아이템 | **판매금액 정정** (되돌리기/재분배) | 되돌릴 금액을 보여준 뒤 확인 |
| 📦 아이템 | **아이템 완전 삭제** | 되돌릴 금액 + 경고 후 확인 |
| 💰 잔액 | 지급 | 지급 후 남는 잔액 표시 |
| ⚙️ 관리 | **최근 지급 취소** | 대상·금액 표시 후 확인 |
| ⚙️ 관리 | 혈맹원 추가 · 아이디 변경 · 탈퇴 | 병합·잔액 잔존 시 재확인 |
| ⚙️ 관리 | 분배비중 · 서버 · 한자표기 변경 | 한 번 확인 |
| ⚙️ 관리 | 아이디 변경 이력 조회 | — |
| 📋 게시판 | 글쓰기 (누구나) · 공지 (관리자) · 삭제 (관리자) | — |
| 🤝 연합 | 연합 정산 등록 · 삭제 | 한 번 확인 |
| ⚙️ 관리 | **앱 이름 변경 · 관리자 PIN 교체** | 마스터관리자만 |
| ⚙️ 관리 | 참여횟수 재계산 · 시트 정돈 · 디스코드 알림 · 시즌 서버 설정 | 한 번 확인 |
| ⚙️ 관리 | **혈비 계정을 혈맹운영비로 통일** | 한 번 확인 |
| ⚙️ 관리 | **시즌 종료** | `시즌종료` 입력 |
| ⚙️ 관리 | **기존 파일에서 가져오기** | 주소 + `가져오기` 입력 |
| ⚙️ 관리 | **최초 설치** | `설치` 입력 |
| ⚙️ 관리 | **공장 초기화** | `전부삭제` 입력 |

**되돌릴 수 없는 작업(굵은 글씨 중 아래 4개)은 정해진 문구를 정확히 입력해야만 실행됩니다.**
폰에서 잘못 눌러 시즌이 끝나는 일을 막기 위한 장치이고, 이 검사는 서버에서 합니다.
