# 배포 가이드 (처음 1회, 약 15분)

순서대로 따라오시면 됩니다. **①②는 PC에서, ③④는 어디서든, ⑤는 폰에서** 하세요.

## ① 구글시트에 v8.0 코드 넣기

1. 정산 스프레드시트 열기 → 상단 **확장 프로그램 → Apps Script**
2. 기존 코드를 **전부 지우고**, 이 저장소의 [`apps-script/GuildManager_v8_0.gs`](../apps-script/GuildManager_v8_0.gs) 내용을 **전부 붙여넣기**
3. 💾 저장
4. 스프레드시트로 돌아와 새로고침 → 메뉴 **[🎮 길드정산] → [🔄 데이터 보존 업그레이드]** 1회 실행
   - 사용안내 시트가 v8.0 내용으로 갱신되고, 시트 보호도 다시 적용됩니다
   - 잔액·누적기록·시즌 기록은 그대로 보존됩니다

> ⚠️ 붙여넣기 전에 기존 코드를 어딘가에 백업해두면 마음이 편합니다.

## ② 웹앱 배포 + 토큰 발급

### 배포

Apps Script 편집기에서 우측 상단 **[배포] → [새 배포]**

| 항목 | 설정값 |
|---|---|
| 유형 (⚙️) | **웹 앱** |
| 실행 계정 | **나** |
| 액세스 권한이 있는 사용자 | **모든 사용자** ← 여기가 핵심 |

**[배포]** 를 누르면 나오는 `https://script.google.com/macros/s/.../exec` 주소를 복사해두세요. → 이게 `GAS_URL`

> **"모든 사용자"로 열어도 괜찮은가요?**
> 네. Vercel 서버에는 구글 로그인 세션이 없어서, "나만"으로 두면 아예 연결이 안 됩니다.
> 대신 아래에서 발급하는 토큰이 없는 요청은 `doPost`가 전부 거부합니다.
> 토큰은 Vercel 서버 환경변수에만 있고 브라우저로는 내려가지 않습니다.

### 토큰 발급

스프레드시트 메뉴 **[🎮 길드정산] → [🔑 웹 API 토큰 (Vercel 앱 연동)]**
→ 나오는 48자 문자열을 복사해두세요. → 이게 `GAS_TOKEN`

## ③ Vercel에 배포

1. [vercel.com/new](https://vercel.com/new) 로그인 (GitHub 계정으로)
2. **Add New → Project** → 이 저장소(`rhrjsgks-jarvis/guild`) 선택 → **Import**
3. **Project Name 을 `guild-manager` 로 지정** ← 이 이름이 그대로 주소가 됩니다

   | Project Name | 접속 주소 |
   |---|---|
   | `guild-manager` | `https://guild-manager.vercel.app` |

   `gyeongwon-ax-hub` → `gyeongwon-ax-hub.vercel.app` 와 같은 방식입니다.
   이미 누가 쓰는 이름이면 거절당하니, 그때는 `guild-dia`·`guild-settle` 같은 다른 이름을 쓰세요.
   나중에 Settings → General → Project Name 에서 바꿔도 주소가 따라옵니다.

4. 빌드 설정은 건드리지 말고 (Next.js 자동 인식), **Environment Variables** 에 4개 등록:

| Name | Value |
|---|---|
| `GAS_URL` | ②에서 복사한 `.../exec` 주소 |
| `GAS_TOKEN` | ②에서 발급받은 48자 토큰 |
| `ADMIN_PIN` | 직접 정하는 관리자 비밀번호 (6자리 이상 권장) |
| `SESSION_SECRET` | 아무 긴 임의 문자열 (예: `openssl rand -base64 32` 결과) |

5. **Deploy**

> 저장소의 기본 브랜치가 `claude/mobile-app-web-deploy-nsr2o2` 라서, Vercel이 이 브랜치를
> 자동으로 Production Branch 로 잡습니다. 앞으로 이 브랜치에 push 되면 1~2분 뒤 자동 반영됩니다.
> (Settings → Git → Production Branch 에서 언제든 바꿀 수 있습니다)

## ④ 연결 확인

배포된 주소 뒤에 `/api/health` 를 붙여서 열어보세요.

```
https://<앱주소>.vercel.app/api/health
```

이렇게 나오면 성공입니다:

```json
{
  "ok": true,
  "env": { "GAS_URL": true, "GAS_TOKEN": true, "ADMIN_PIN": true, "SESSION_SECRET": true },
  "sheet": { "connected": true, "version": "8.0", "unit": "다이아" },
  "msg": "모든 설정이 정상입니다. 🎉"
}
```

문제가 있으면 `msg` 에 무엇이 잘못됐는지 한국어로 나옵니다. → [자주 막히는 곳](#자주-막히는-곳)

## ⑤ 폰 홈 화면에 추가

앱 주소를 폰 브라우저로 열고:

- **iPhone (사파리)** — 하단 공유 버튼 ⬆️ → **홈 화면에 추가**
- **Android (크롬)** — 우측 상단 ⋮ → **앱 설치** 또는 **홈 화면에 추가**

홈 화면 아이콘으로 열면 주소창 없이 전체화면으로 뜹니다.

**길드원에게는 이 주소를 그냥 공유하면 됩니다.** PIN 없이는 조회만 되니 안전합니다.
앱 **[⚙️ 관리]** 탭의 **📤 길드원에게 공유하기** 카드에 QR·링크 복사·공유 버튼이 있습니다.
관리자만 같은 탭에서 PIN을 입력하면 등록·분배·지급 버튼이 나타납니다.

## 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| `/api/health` 에 "구글이 로그인 화면을 돌려줬습니다" | 배포 액세스가 "모든 사용자"가 아님 | [배포 관리] → 편집 → 액세스: **모든 사용자** → 새 버전 |
| "API 토큰이 아직 발급되지 않았습니다" | 시트에서 토큰을 안 만듦 | 메뉴 **[🔑 웹 API 토큰]** 1회 실행 |
| "인증에 실패했습니다" | `GAS_TOKEN` 값이 시트의 토큰과 다름 | 메뉴에서 현재 토큰 확인 → Vercel 값 교체 → **Redeploy** |
| "doPost 함수가 없을 수 있습니다" | v8.0 코드를 붙여넣고 재배포를 안 함 | Apps Script에 v8.0 붙여넣기 → [배포 관리] → 새 버전 |
| 환경변수를 고쳤는데 그대로 | Vercel은 재배포해야 반영됨 | Deployments → 최신 항목 ⋯ → **Redeploy** |
| 사진 첨부해도 참여자 자동 체크가 안 됨 | Advanced Drive Service 미활성 | Apps Script 좌측 **[서비스] → [+] → "Drive API"** 추가 (사진 저장·링크는 이것 없이도 됩니다) |
| 특정 멤버만 계속 OCR로 안 잡힘 | 게임 표시 이름이 멤버DB 표기와 다름 | 멤버DB **D열 "게임표시명"** 에 실제 게임 화면 문자열을 그대로 입력 |
| 앱을 새로고침해도 옛 화면 | 서비스워커가 껍데기를 들고 있음 | 앱 완전히 종료 후 재실행, 또는 브라우저에서 새로고침 |
| PIN을 잊음 | — | Vercel `ADMIN_PIN` 값을 바꾸고 Redeploy |
