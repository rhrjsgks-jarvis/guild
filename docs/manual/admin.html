2 / 6아이템 · 분배 산식v11.6.1

📦 아이템 — 등록부터 지급까지레이드 직후엔 금액을 모르는 게 정상입니다

1

등록 관리자

아이템명 + 참여자를 체크합니다. 인증샷을 넣으면 사진 속 이름을 읽어 자동으로 체크해줍니다 — 여러 장 넣을 수 있고, 장마다 찾은 사람이 더해집니다 (직접 체크한 것은 안 지웁니다). 상태는 ⏳미분배.

2

분배 관리자

팔린 뒤 판매금액을 넣습니다. 누가 얼마 받는지 그 자리에서 미리 보여줍니다 — 이 숫자가 실제 결과와 같습니다. 상태는 ✅분배완료.

3

지급 관리자

실제로 다이아를 보낸 뒤 [💰 잔액] 화면에서 지급 처리합니다 (금액을 비우면 전액). 잘못 눌렀으면 ↩️ 최근 지급 취소.

등록 칸급하면 아이템명과 참여자만 넣어도 됩니다

칸이렇게
아이템명자동완성 — 中文 · English 로 쳐도 찾아집니다. 고르면 저장되는 이름은 언제나 한국어입니다
레이드 날짜잡은 날. 등록일과 같으면 비워도 됩니다
보스자동완성 — 보스만 제안됩니다 (아이템에 안 묻힙니다)
루팅 서버 / 캐릭터떨어진 서버와 먹은 사람
참여자칩을 눌러 체크. 서버·클래스로 좁혀도 이미 체크한 사람은 절대 안 숨습니다
인증샷여러 장 가능. 없어도 등록됩니다

티어 칸은 없습니다

사전에서 고르면 등급 테두리·티어·아이콘이 알아서 붙습니다. 사전에 없는 이름도 그냥 칠 수 있습니다 — 새 아이템 때문에 등록이 멈추면 안 되니까요.

미루지 말고 먼저 등록하세요

급하면 아이템명과 참여자만 넣고 [등록]하세요. 나머지는 나중에 🏷️ 로 채우면 됩니다. 미루다 인증샷을 잃는 게 훨씬 큰 손해입니다.

분배 산식다이아는 사라지지도 생겨나지도 않습니다

운영비 = 총액 × 10% (버림)
분배가능 = 총액 − 운영비
기본1인당 = 분배가능 ÷ 인원 (버림)
각자 = 기본1인당 × 비중% (버림)
잔여 = 남은 몫 → 전액 운영비
10,000 다이아를 10명이 · 그중 한 명은 비중 50%
🏦 혈맹운영비 (10%)1,000
기본 1인당 (9명)900
비중 50% 인 사람450
남은 450 → 운영비로+450
혈맹운영비 최종1,450

비중은 [관리] → 혈맹원에서

기본값은 100%입니다. 남는 몫은 참여자 누구에게도 얹지 않고 전액 혈맹운영비로 갑니다 — 한 사람만 금액이 달라지면 버그로 오해받기 때문입니다.

3 / 6연합 · 인증샷v11.6.1

🤝 연합 — 아이템 하나 = 여러 서버화면은 언제나 묶음(=아이템) 단위

1

등록 관리자

아이템명 + 참여 서버별 인원을 한 번에 넣습니다.
예) 01서버 10명 · 02서버 5명 · 05서버 3명
인증샷은 서버 줄마다 붙입니다 — 줄 안의 📷 01서버 사진 추가. 여러 장 가능하고 없어도 됩니다.

＋

서버 추가 관리자

"우리 서버도 갔었다"는 이야기가 늦게 와도 ＋ 로 서버·인원·사진을 더할 수 있습니다. 사진은 더한 그 서버 줄에 붙습니다.
이미 넣은 줄을 고치려면 수정 을 쓰세요 (금액 넣기 전이면 관리자도 가능).

2

금액 넣기 관리자

팔린 뒤 판매금액을 넣으면 혈비를 뗀 나머지가 인원수 비례로 각 서버에 나뉩니다.

100,000 다이아 · 01서버 10명 + 02서버 5명
🏦 혈맹운영비 (10% + 잔여)10,000
01 서버 · 10명60,000
02 서버 · 5명30,000
합계 = 판매금액100,000

연합은 개인 잔액을 건드리지 않습니다

  • 연합 인원은 우리 멤버DB에 없어서 몇 명인지만 셉니다
  • 움직이는 것은 혈맹운영비 한 계정뿐입니다 (혈비 10% + 잔여)
  • 참여횟수도 오르지 않습니다 — 우리 레이드 출석이 아니니까요
  • 금액을 넣기 전에는 서버별 누적에 안 잡히고 ⏳ 대기 N명 으로만 보입니다

📷 인증샷연합은 서버별 · 앱 안에서 바로 보기

아이템명이나 연합 아이템을 누르면 참여자 명단과 인증샷이 열립니다. 사진을 누르면 앱 안에서 크게 보입니다 — 새 탭으로 나가지 않습니다.

연합은 서버마다 그 서버의 사진이 나옵니다. v11.2 이전에 등록한 건은 사진이 첫 서버 줄에 몰려 있는데, 그대로 보입니다.

인원수는 사람이 넣은 값이 우선입니다

  • 사진이 읽은 인원수는 제안일 뿐입니다
  • 숫자를 한 번이라도 직접 고치면 사진이 그 값을 덮어쓰지 않습니다
  • 사진을 붙인 그 줄에만 채워집니다 — 다른 서버 줄은 건드리지 않습니다
  • 읽은 값은 📷1 13명 처럼 그 줄에 함께 보여줍니다
  • 사진 속 인원과 다르면 직접 고쳐 넣으세요

아이템 · 보스 이름을 한국어 / 中文 / English 로 모아두는 표입니다. 채우는 만큼 앱이 똑똑해집니다.

헷갈리는 것

  • 저장되는 이름은 언제나 한국어입니다 — 「不變項鍊」을 골라도 기록엔 '불변의 목걸이'
  • 中文·English 빈칸은 "아직 확인 못 했다"는 뜻 — 한국어 그대로 보여줍니다
  • 사전에 없는 이름도 그대로 입력됩니다 (막으면 새 아이템 등록이 멈춥니다)
  • 티어 빈칸과 0티어 는 다릅니다 — 빈칸 = 티어 개념 없음(마법서·정수) / 0티어 = 장비인데 표기 없음
  • 📋 붙여넣기로 여러 개 — 표를 복사해 한 번에. 탭·쉼표·슬래시를 다 받습니다. 이미 있는 한국어는 건드리지 않습니다

레이드일 · 보스 · 루팅서버 · 루팅캐릭터 · 아이템명은 다이아를 한 톨도 안 만집니다. 그냥 이름표라 잘못 적으면 다시 적으면 됩니다 — 그래서 분배가 끝난 건에도 쓸 수 있습니다.
맨 위 주황색 칸이 지금 저장된 원문입니다. 8/14 수룡 / 불변의 목걸이 / 차무식루팅 처럼 한 칸에 몰아 적던 것을 옮겨 담으면 보스별 · 사람별로 찾을 수 있는 자료가 됩니다.

왜 정산 전만 관리자에게 열려 있나요

아직 금액을 안 넣은 건은 다이아가 하나도 안 움직인 상태라 틀려도 고치면 그만입니다. 반대로 정산된 건은 고칠 때마다 혈맹운영비 잔액이 실제로 움직입니다 — 그래서 마스터 전용입니다. 이 판정은 구글시트가 합니다. 앱을 고쳐도 뚫리지 않습니다.

돈이 움직이는 수정은 두 번 물어봅니다

이미 나눠준 다이아를 분배 시점 금액 그대로 회수한 뒤 새 명단·새 금액으로 다시 나눕니다. 저장하기 전에 바뀔 숫자(혈비 얼마 → 얼마)를 보여주니 확인하고 누르세요.
이미 지급✓ 된 사람이 있으면 회수할 잔액이 없어 아예 막힙니다.

5 / 6주의 · 관리 도구 · 레이드 시간표v11.6.1

⚠️ 꼭 알아두실 것

팝업은 바깥을 눌러도 안 닫힙니다

실수로 닫혀 입력하던 내용이 날아가는 일을 막기 위해서입니다. 닫으려면 ✕(오른쪽 위) 또는 아래쪽 취소·저장·닫기, 그리고 폰 뒤로가기.

참여횟수와 다이아는 다른 숫자입니다

참여횟수는 등록할 때 확정되는 레이드 출석 기록입니다. 분배 금액과는 아무 상관이 없고, 참여자를 고치면 등록 이력 전체를 다시 세어 맞춥니다.

기록은 지워지지 않습니다

혈맹원을 탈퇴시켜도 잔액·참여 이력이 있으면 이름 (미등록) 으로 남습니다. 분배대기중·지급기록·작업기록은 어떤 경우에도 건드리지 않습니다.
