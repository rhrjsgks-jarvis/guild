# 관리자 설명서

## 시작 — PIN 하나면 문이 열립니다

혈맹원 설명서의 내용은 관리자도 그대로 씁니다. 여기는 **관리자만 할 수 있는 것**만 다룹니다.

![⚙️ 관리 — 홈 아이콘 맨 마지막](shots/admin-locked.png)
![PIN 을 넣으면 열립니다](shots/admin-unlocked.png)

**⚙️ 관리**는 홈 아이콘 중 **맨 마지막**에 있습니다. 엄지가 잘 닿는 자리에 두면
PIN 창과 위험한 도구가 실수로 눌립니다 — 일부러 멀리 뒀습니다.

한 번 열면 **이 기기에서 30일** 유지됩니다. 공용 PC라면 쓰고 나서 꼭 [잠그기].

| 등급 | 할 수 있는 것 |
|---|---|
| 혈맹원 | 보기 + 📋 게시판 글쓰기 (정산 데이터에는 손댈 수 없음) |
| **관리자** | 등록 · 분배 · 지급 · 연합 · 명단 · 용어 · 레이드·루팅 정보 |
| **마스터관리자** | 위 전부 + 분배완료 건 수정 + 앱 이름 · 관리자 PIN 변경 |

> 권한은 **"누구인가"가 아니라 "무엇을 만질 수 있는가"** 로 나뉩니다.
> 되돌리기 어려운 것일수록 위 등급으로 올라갑니다.

**공유 링크**는 그대로 뿌려도 됩니다. 받은 사람은 **조회만** 됩니다.

## 📦 아이템 ① 등록 — 레이드 직후 30초

![등록 칸 — 위에서 아래로 채우면 끝](shots/items-admin.png)

| 칸 | 이렇게 |
|---|---|
| 아이템명 | 자동완성. **中文·English로 쳐도** 찾아집니다 |
| 레이드 날짜 | 잡은 날. 등록일과 같으면 비워도 됩니다 |
| 보스 | 자동완성 (**보스만** 제안됩니다 — 아이템에 안 묻힙니다) |
| 루팅 서버 / 루팅 캐릭터 | 떨어진 서버와 먹은 사람 |
| 참여자 | 칩을 눌러 체크 |
| 인증샷 | 여러 장 가능. **없어도 등록됩니다** |

- **티어 칸은 없습니다.** 사전에서 고르면 알아서 붙습니다.
- 자동완성으로 고르면 저장되는 이름은 **언제나 한국어**입니다.
- 사전에 없는 이름도 그냥 칠 수 있습니다 — 새 아이템 때문에 등록이 멈추면 안 되니까요.
- 사진을 올리면 참여자를 자동으로 찾아 **더합니다.** 직접 체크한 것은 안 지웁니다.
- 서버·클래스로 좁혀도 **이미 체크한 사람은 절대 숨지 않습니다.**

> 급하면 **아이템명과 참여자만** 넣고 [등록]하세요.
> 나머지는 나중에 🏷️ 로 채우면 됩니다. 미루다 인증샷을 잃는 게 더 큰 손해입니다.

## 📦 아이템 ② 분배 → 지급

![판매금액을 넣으면 결과가 미리 보입니다](shots/distribute.png)

판매금액만 넣으면 **누가 얼마 받는지 그 자리에서** 보여줍니다.

```
혈맹운영비 10%  →  남은 금액을 참여자에게 인원수 비례
원 단위 잔여    →  전액 혈맹운영비
```

- 분배비중이 100%가 아닌 사람은 그만큼만 받고, **남는 몫은 운영비**로 갑니다
  (위 그림의 `대서과Z (50%)` 가 그 경우입니다).
- **확인 화면의 숫자가 실제 결과와 같습니다.** 다르면 버그입니다 — 알려주세요.

**지급**은 [잔액] 화면에서 [지급] → 금액 입력(비우면 전액).
잘못 눌렀으면 **↩️ 최근 지급 취소** 로 되돌립니다.

## 🏷️ 고치기 — 돈을 안 만지는 수정

![🏷️ 는 분배가 끝난 건에도 씁니다](shots/loot-edit.png)

| 상황 | 누가 |
|---|---|
| ⏳미분배 건의 이름·참여자 | 마스터관리자 |
| ✅분배완료 건의 참여자·금액 | 마스터관리자 (되묻기를 거칩니다) |
| **레이드일·보스·루팅·아이템명** | **관리자** — 🏷️ 버튼 |

🏷️ 는 **분배가 끝난 건에도** 쓸 수 있습니다. **다이아를 한 톨도 움직이지 않기 때문입니다.**

맨 위 주황색 칸이 **지금 저장된 원문**입니다. 아래 칸에 옮겨 담으면
`8/14 수룡 / 불변의 목걸이 / 차무식루팅` 처럼 한 칸에 몰아 적던 것이
보스별·사람별로 찾을 수 있는 자료가 됩니다.

## 🤝 연합 — 금액은 나중에

![묶음(=아이템) 단위로 보입니다](shots/alliance.png)

혈맹 내부 분배와 **완전히 분리된 장부**입니다. 개인 잔액은 어느 단계에서도 안 건드립니다.

**① 등록 (금액 없이)** — 아이템명 + 참여 서버별 인원 + 레이드일·보스·루팅 + 인증샷.

> 레이드 직후엔 아직 안 팔려서 금액을 모르는 게 정상입니다.
> 그때 금액을 요구하면 등록이 미뤄지고 인증샷을 잃어버립니다.

- 한 아이템에 **여러 서버**가 들어갑니다. 화면은 언제나 묶음(=아이템) 단위입니다.
- 인증샷은 **줄마다 그 서버의 것**입니다.
- 사진이 읽은 인원수는 **직접 고친 값을 덮어쓰지 않습니다.**

**② 정산** — 판매금액을 넣으면 혈비 10%를 떼고 **인원수 비례**로 서버에 나눕니다.
혈비는 `혈맹운영비` 잔액에 실제로 적립됩니다.

**③ 참여 서버 추가** — "우리 서버도 갔었다"가 늦게 옵니다. **관리자**가 [＋]로 줄을 더합니다.
**더하기만** 되고 기존 줄은 못 고칩니다 — 그래서 관리자에게 열려 있습니다.

## 👥 혈맹원 관리

![서버·클래스로 좁혀 보면 40명도 한눈에](shots/admin-roster.png)

| 기능 | 설명 |
|---|---|
| 추가 | 한 명도, 명단 사진으로 여러 명도 |
| 아이디 변경 | 이미 있는 이름으로는 못 바꿉니다 |
| 이전 아이디에서 가져오기 | 개명 전 기록을 이어붙입니다 |
| 탈퇴 | 지우는 게 아니라 명단에서 빼기 |
| 서버 일괄 지정 | 40명을 한 화면에서 |

**한 사람에 지정하는 값** — 분배비중(1~100%, 기본 100) · 서버(01~12) ·
한자표기(**눈으로 확인한 것만**) · 클래스(공식 13종).

> 서버·클래스가 비어 있으면 나중에 **좁혀 보기가 안 됩니다.** 미리 채워두세요.
> 화면 위 주황색 알림이 몇 명 비었는지 알려줍니다.

## 📚 용어 사전 — 이게 앱의 절반입니다

![세 언어를 한 표에](shots/admin-terms.png)
![언어를 바꾸면 아이템명도 바뀝니다](shots/items-zh.png)

아이템·보스 이름을 **한국어 / 中文 / English** 로 모아두는 표입니다. 이것이 채워지면:

- 등록할 때 **어느 언어로 쳐도** 자동완성됩니다.
- 목록에 **등급 테두리**(🟣전설 · 🟡신화) · **티어 배지** · **공식 아이콘**이 붙습니다.
- 언어를 바꾸면 아이템·보스 이름이 함께 번역됩니다.

| | |
|---|---|
| 저장되는 이름 | **언제나 한국어.** 「不變項鍊」을 골라도 기록엔 '불변의 목걸이' |
| 中文·English 빈칸 | "아직 확인 못 했다"는 뜻 — 한국어 그대로 보여줍니다 |
| 사전에 없는 이름 | 그대로 입력됩니다 (막으면 새 아이템 등록이 멈춥니다) |
| 같은 한국어 두 줄 | 시트가 거부합니다 |
| 티어 빈칸 vs `0티어` | **다릅니다.** 빈칸 = 티어 개념 없음(마법서·정수) / 0티어 = 장비인데 표기 없음 |

**📋 붙여넣기로 여러 개** — 표를 복사해 한 번에 넣습니다. 탭·쉼표·슬래시를 다 받습니다.
**이미 있는 한국어는 건드리지 않습니다** (고쳐둔 표기가 날아가지 않게).

## 📋 공지 올리기 · 글 삭제

![관리자에게만 체크칸이 하나 더 있습니다](shots/board-write.png)

게시판은 **앱에서 유일하게 PIN 없이 열려 있는 쓰기 경로**입니다. 관리자는 두 가지가 더 됩니다.

| | |
|---|---|
| **📌 공지로 올리기** | 글쓰기 창에 관리자에게만 보이는 체크칸. 목록 맨 위에 고정되고 앱 윗줄에 띠로 뜹니다 |
| **삭제** | 글을 펼치면 [삭제] 가 보입니다. 혈맹원에게는 안 보입니다 |

- 공지 권한은 **PIN 을 푼 이 기기인지**로만 정해집니다. 체크칸을 흉내 내서 보내도
  공지가 되지 않습니다 — 서버가 기기 인증만 봅니다.
- 혈맹원 글은 **한 기기에서 10분에 5건**으로 제한됩니다. 관리자도 같습니다.
- 게시판은 정산 데이터에 손대지 않습니다. 여기서 무슨 일이 있어도 잔액은 안전합니다.

> 시트에 [게시판] 탭이 없으면 "시트를 먼저 만들어달라"는 안내가 나옵니다.
> 도구 **[📐 시트 정돈]** 을 한 번 실행하면 만들어집니다.

## 버전 관리 · 문제 해결

제목 옆에 앱 버전이 있습니다. **⚠️ 경고가 뜨면 시트가 옛 버전**입니다.

```
① 새 .gs 를 Apps Script 에 붙여넣기
② [배포] → [배포 관리] → 연필 → 새 버전 → 배포
③ 앱에서 새로고침
```

> `.gs` 를 붙여넣기만 하고 **새 버전으로 재배포하지 않으면 아무것도 안 바뀝니다.**
> 가장 흔한 실수입니다. 그리고 **시트를 손대기 전에 사본을 떠두세요.**

버전이 `11.6.1` 처럼 **세 자리**면 세 번째 자리는 앱에만 있는 것입니다 —
화면만 바뀐 것이라 `.gs` 를 다시 붙여넣을 필요가 없습니다.

| 증상 | 원인 |
|---|---|
| `.gs` 를 고쳤는데 그대로 | [배포 관리] → 새 버전을 안 함 |
| 앱이 로그인 화면을 받음 | Apps Script 배포 액세스가 "모든 사용자"가 아님 |
| 환경변수를 바꿨는데 그대로 | Vercel 은 **Redeploy** 해야 반영됨 |
| 등급 테두리가 검정 | 아이템명이 사전과 다름 (🏷️ 로 공식명 선택) |
| 언어를 바꿔도 이름이 한국어 | 위와 같은 원인 — 사전에 있는 것만 번역됨 |
| 아이콘이 안 나옴 | 사전 `이미지` 칸이 빈 것 (보스는 원래 없습니다) |
| 같은 사람이 두 줄 | 아이디 변경 후 안 이어붙임 |
| 운영비 계정이 두 개 | 도구 **[🏦 혈비 계정을 혈맹운영비로 통일]** 실행 |
| 사람이 안 보임 | 서버 칩이나 클래스 드롭다운이 켜져 있는지 확인 |
