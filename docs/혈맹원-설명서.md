# 혈맹원 설명서

## 처음 오셨나요? 30초면 끝납니다

**로그인 없습니다. 앱 설치 없습니다.** 링크를 누르면 그냥 열립니다.

![첫 화면 — 여기서 다 시작합니다](shots/home.png)
![내 잔액이 여기 있습니다](shots/balance.png)

윗칸 **「지금 상황」** 은 오늘 어디까지 왔는지 알려주는 요약입니다.
아랫칸 **「모든 화면」** 이 실제로 들어가는 문입니다. 아무거나 눌러 보세요 —
**혈맹원은 무엇을 눌러도 망가뜨릴 수 없습니다.** 보기만 되고 고치기는 안 됩니다.

> 폰 홈에 두고 쓰시려면 브라우저 메뉴에서 **[홈 화면에 추가]** 를 누르세요.
> 그러면 진짜 앱처럼 아이콘이 생깁니다.

### 제일 먼저 볼 것 — 💰 잔액

내 이름을 찾아서 **주황색 숫자**를 보면 됩니다. 그게 아직 못 받은 다이아입니다.

| 보이는 것 | 뜻 |
|---|---|
| 주황색 큰 숫자 | **아직 못 받은 것** — 관리자가 지급하면 0이 됩니다 |
| 초록색 `완료` | 지금까지 실제로 받은 누적 |
| 이름 앞 `01` | 서버 번호 |
| 이름 아래 `기사 · 참여 31회` | 클래스와 레이드 참여 횟수 |
| 맨 위 **혈맹운영비** | 사람이 아니라 **길드 금고**입니다. 아무도 못 가져갑니다 |

내 이름이 안 보이면 위쪽 **이름 검색**에 두 글자만 쳐 보세요.

## 찾기 · 읽기 — 세 가지만 알면 됩니다

### ① 좁혀 보기 — 서버는 여러 개, 클래스는 하나

**서버 칩**은 여러 개를 같이 누를 수 있습니다 (01 + 03 동시에).
**클래스**는 드롭다운이라 한 번에 하나입니다.
둘을 같이 쓰면 **겹칩니다** — 「01서버의 기사」처럼요.

- 아무것도 안 고르면 **전원**이 나옵니다. 그게 기본입니다.
- **「전체 클래스」와 「클래스 미지정」은 다릅니다.** 미지정을 고르면
  아직 클래스를 안 넣은 사람만 나옵니다.
- 다시 누르면 풀립니다. 사람이 사라진 것 같으면 필터가 켜져 있는지 보세요.

### ② 아이템 이름의 테두리와 배지

![아이템 — 테두리 색이 등급입니다](shots/items.png)
![연합 — 서버끼리 나눈 몫](shots/alliance.png)

| 테두리 | 뜻 |
|---|---|
| 🟣 **보라색** | 전설 |
| 🟡 **황금색** | 신화 |
| ⚫ **검정색** | 사전에 없는 이름 — 관리자가 아직 정리 못 한 것입니다 (틀린 게 아닙니다) |

이름 뒤 `3티어` 배지는 **사전에 있을 때만** 붙습니다.
마법서·정수처럼 티어라는 개념이 아예 없는 것은 배지가 안 붙는 게 정상입니다.

### ③ 인증샷은 눌러서 봅니다

`📷 2장` 이라고 적힌 것을 누르면 **앱 안에서 바로** 열립니다.
다른 앱으로 튕겨 나가지 않습니다.

### 자주 묻는 것

| 이런가요? | 이렇습니다 |
|---|---|
| 숫자가 안 바뀝니다 | 오른쪽 위 **↻** 를 누르세요. 옆에 마지막으로 받아온 시각이 나옵니다 |
| 내 이름이 없습니다 | 필터가 켜져 있거나, 명단에 아직 안 들어간 것입니다 → 관리자에게 |
| 잔액이 이상합니다 | 관리자에게. 분배 당시 기록이 남아 있어 되돌릴 수 있습니다 |
| 이름이 두 개로 보입니다 | 개명 후 기록을 안 이어붙인 것입니다 → 관리자에게 |
| 아이템 이름이 검정 테두리 | 사전에 없는 이름입니다. 알려주시면 관리자가 고칩니다 |
| 뒤로가기를 누르면? | 팝업만 닫힙니다. **앱 밖으로 안 나갑니다** |

**고장난 게 아니라 이상해 보이는 것**이 대부분입니다. 편하게 물어보세요.
